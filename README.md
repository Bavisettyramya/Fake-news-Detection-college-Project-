# Fake-news-Detection-college-Project
This repository contains a RESTful API for detecting fake news using machine learning and natural language processing. It allows users to submit news content and receive a prediction indicating whether the news is real or fake.

Features

Predicts whether a news article is fake or real

Built using Python and Flask (or FastAPI)

Trained on a labeled fake/real news dataset

Provides a simple and accessible HTTP API

JSON responses for easy integration


Tech Stack

Language: Python

Framework: Flask (or FastAPI)

ML Model: Logistic Regression / Naive Bayes / Random Forest (customizable)

Libraries: scikit-learn, pandas, NumPy, joblib


Endpoints

POST /predict

Description: Predicts the authenticity of a news article.
